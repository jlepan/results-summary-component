# **blog-preview-card**

Ce projet est un exercice réalisé dans le cadre des défis de [Frontend Mentor](https://www.frontendmentor.io/). 
Il consiste à créer un résumé de résultats en suivant la maquette donnée.
Nous avons aussi la possibilité d'utiliser un fichier data.json (fourni) afin d'ajouter dynamiquement les résultats et la moyenne de ces derniers.

## Technologies utilisées

- HTML5
- CSS3
- JavaScript
